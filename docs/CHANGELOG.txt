## 2026-11-13 — Phase 0 foundation implemented
Phase: Phase 0 / v0.0.1
Spec:  §4, §5.1, §6, §6.1, §6.2, §7.4, §10.4, §13, §14, §15, §16 Phase 0

Added:
- Go module github.com/maymeow/fjo (Go 1.27.4 toolchain; deps: cobra,
  go.yaml.in/yaml/v3, x/term, x/net/idna). git repo initialized (branch main).
- cmd/fjo/main.go; internal/cli root command with global flags --color,
  --verbose, --debug; `fjo version` and `fjo --version` (§15 format);
  cobra built-in `help` and `completion`.
- internal/app Factory (gh cmdutil.Factory pattern), lazy cached config.
- internal/fjoerr typed errors (Kind) + gh-aligned exit codes (B-11).
  Unknown commands / bad flags / bad args -> exit 10; Ctrl+C -> 130.
- internal/config: schema v1, host ID normalization (§6.2, incl. port,
  subpath, IDN, IPv6), strict YAML parsing (unknown keys rejected),
  validation, precedence resolver (flag > env > config > default),
  atomic save (temp + rename, 0600/0700). Config dir: FJO_CONFIG_DIR >
  XDG_CONFIG_HOME/fjo > OS config dir.
- internal/iostreams: TTY detection, color policy (NO_COLOR, FJO_NO_COLOR,
  CLICOLOR_FORCE, TERM=dumb), FJO_PROMPT_DISABLED.
- internal/logging: slog logger with redaction of Authorization headers,
  token/password params, URL credentials, 40-hex tokens and registered
  secrets (FJO_TOKEN registered at startup). Error messages are redacted too.
- Makefile, scripts/build.ps1 (Windows), .gitignore,
  .forgejo/workflows/ci.yaml (3-OS matrix on self-hosted runners, pinned
  staticcheck v0.8.2 / govulncheck v1.9.0).
- Docs skeleton: README, INSTALL, CONTRIBUTING, SECURITY, CODE_OF_CONDUCT
  (placeholder), CHANGELOG.md, docs/architecture, authentication, commands,
  compatibility (exit codes, env vars, gh parity table), development
  (runner setup).

Changed:
- IMPLEMENTATION §10.4 exit-code table replaced with the gh-aligned table.
- §16 Phase 0 tasks ticked (except runners and pinned swagger).

Deviations from spec:
- No LICENSE file yet (B-33). No .goreleaser.yaml yet (release phase).
- --host, --repo, --json, --jq, --template, --no-pager not added yet: they
  have no meaning before Phase 1-3 (§5.1 "only where meaningful").
- Config commands that do not need config (`version`, help) work even when
  config.yaml is invalid; other commands will fail with exit 1 + hint.

Tests:
- go vet, gofmt, staticcheck v0.8.2: clean. govulncheck v1.9.0: no vulnerabilities.
- go test ./...: all pass on windows/amd64. Coverage: cli 90.8 %,
  logging 95.7 %, fjoerr 89.7 %, app 85.7 %, config 81.1 %, iostreams 80 %,
  version 72.7 %, build 70.6 %.
- Manual smoke test of bin/fjo.exe: --help, version, -v, unknown command
  (exit 10), broken config + version (exit 0).
- Cross-compile OK: linux/amd64, linux/arm64, darwin/amd64, darwin/arm64,
  windows/arm64; `GOOS=linux go vet` clean.
- NOT run: go test -race (no gcc on this machine, B-35); tests on Linux/macOS
  and the CI workflow itself (no runners yet).

Notes / next steps:
- Committed as the initial commit on main (local only, not pushed).
- Set up runners, run CI once, pin Forgejo 15/17 swagger -> Phase 0 complete.
- Then Phase 1 (API client + auth).
