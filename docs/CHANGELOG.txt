## 2026-11-13 — Phase 1 (part 2): `fjo api`
Phase: Phase 1 / v0.0.2a
Spec:  §5.9, §7.4, §9.4, §16 Phase 1

Added:
- internal/cli/api (package apicmd), registered in internal/cli/root.go:
  `fjo api <endpoint>` with --hostname (no -h, as gh), -X/--method,
  -F/--field (true/false/null/int64, @file, @-), -f/--raw-field,
  -H/--header, --input FILE|-, --paginate, -i/--include, --silent.
  - Method defaults to GET, POST when fields or --input are given and -X
    is not set (gh).
  - GET/HEAD fields -> query string; with --input the fields also go to the
    query; otherwise a JSON object. Nested keys `a[]=` and `a[b]=`;
    duplicate / conflicting keys are usage errors.
  - --input sets Content-Type: application/json unless -H overrides it.
  - --paginate: GET only, uses Client.Pages (next links only inside the
    instance), merges JSON-array pages into one array; a non-array first
    page is printed as-is.
  - JSON is indented on a TTY, verbatim otherwise. On status >= 400 the
    body goes to stdout and the classified error to stderr (exit 4/11/12/
    13/14). Requires auth (exit 4) via Factory.ClientFor.
  - {owner}/{repo}/{branch} placeholders -> usage error until Phase 2.
- internal/cli/api/api_test.go (TLS httptest server, FJO_HOST + FJO_TOKEN):
  GET, TTY pretty print, query/JSON fields, @file/@-, --input, headers,
  error statuses -> exit codes, --include/--silent, pagination incl.
  relative next links and refusal of a foreign next link, absolute URL
  outside the instance, not logged in, usage errors.
- docs/commands.md: `fjo api` section. docs/compatibility.md: auth + api
  marked done, FJO_TOKEN/FJO_HOST done, api differences listed.

Deviations from spec:
- --paginate merges arrays instead of gh's concatenated pages (documented).
- No --jq/--template/--cache/--preview and no GraphQL (Forgejo has none).

Tests:
- Linux/amd64 (Fedora 44, Go 1.27.4): go test ./... pass; go vet, gofmt,
  staticcheck v0.8.2 clean; govulncheck v1.9.0: no vulnerabilities;
  GOOS=windows and GOOS=darwin go vet clean. Coverage cli/api 90 %.
- Manual smoke: api --help; no host (exit 10); not logged in (exit 4);
  unreachable host (exit 14).
- NOT tested: against a real Forgejo server; -race (no gcc here, B-35).

Notes / next steps:
- Continue with: tests for internal/cli/auth (pattern from cli/api tests:
  httptest.NewTLSServer + f.HTTPTransport + in-memory credentials.Manager),
  app/auth.go, prompt, browser, fsutil; then docs/authentication.md and
  spec §5.1/§5.2/§6; then Docker integration tests vs. Forgejo 15/17.

## 2026-11-13 — Phase 1 (part 1): API client, credential storage, auth commands
Phase: Phase 1 / v0.0.2 (work in progress, continued on another machine)
Spec:  §5.2, §6, §7.1–7.5, §9.1–9.4, §16 Phase 0 (swagger), §16 Phase 1

Decisions (details in BACKLOG):
- B-5:  zalando/go-keyring; keyring failure is an error; plain-text file only
        with explicit `auth login --insecure-storage` (like gh).
- B-8:  swagger specs pinned (Forgejo 15.0.11 and 17.0.1).
- B-12: no global --host; commands take `-h/--hostname` (gh), hidden
        `--host` alias. `fjo api` will use `--hostname` only (no -h, as gh).
- B-13: --limit = total items, pagination internal; --paginate only on `api`.
- B-15: FJO_TOKEN applies to whichever host the command targets; never stored.
- B-16: `auth refresh` dropped until OAuth2.
- B-19: Phase 1 split into 0.0.2a (client + api) and 0.0.2b (keyring + auth).

Added:
- test/fixtures/swagger/forgejo-v15.0.11.json and forgejo-v17.0.1.json from
  code.forgejo.org (templates/swagger/v1_json.tmpl at those tags). The two
  template placeholders (AppVer, AppSubUrl) were replaced with the version
  and "" so the files are valid JSON. sha256 of the patched files:
  15.0.11 2590e146848ddf268bd9735dd3cb0fe398774839dfc2a9b0448f824d4b930c13
  17.0.1  dc84d216e852f0eed59b29db80e0bcebd91e7b127d62ba31ebd0ed9432a60bc3
- internal/api — own thin client:
  - Options{BaseURL, Token, UserAgent, CAFile, Logger, Transport, MaxRetries}.
  - `Authorization: token <PAT>` is sent ONLY to requests inside the
    instance root (same scheme + host + base path; derived from api_url by
    stripping "api/v1/") and stripped from every other request, including
    redirect hops (authTransport). https->http redirects are refused;
    max 10 redirects.
  - Base transport = clone of http.DefaultTransport (keeps HTTP(S)_PROXY /
    NO_PROXY), TLS >= 1.2, optional ca_file added to the system roots.
  - Retries (default 2, exponential backoff, Retry-After capped at 10 s)
    only for GET/HEAD/OPTIONS on 429/502/503/504 and transient net errors.
  - APIError{StatusCode, Method, Message, Errors, URL (sanitized, no
    query), RequestID} mapped to fjoerr kinds: 401 auth, 403 forbidden,
    404 not_found, 409/412/413/422 conflict, 429/5xx unavailable; TLS
    errors -> unavailable with a ca_file hint; net timeout -> timeout.
  - Pagination: ParsePage (Link + X-Total-Count), Client.Pages (follows
    rel=next inside the instance only, loop detection, max pages), generic
    List[T] with --limit semantics (page size min(limit, 50)).
  - Endpoint registry: every endpoint is declared via endpoint(method,
    path); swagger_test.go checks each one exists in both pinned specs.
  - Endpoints so far: GET /user (CurrentUser), GET /version (ServerVersion).
- internal/credentials: Store interface; Keyring (service "fjo:<host ID>",
  account = username, 3 s timeout); File (credentials.yaml next to
  config.yaml, 0600, warning header, deleted when empty); Memory (tests);
  Manager (keyring first, no silent fallback, only one copy kept).
- internal/fsutil.WriteFileAtomic (config.Save now uses it).
- internal/config: host field `ca_file` (absolute path), APIURL(id, host),
  Config.HostIDs / AddUser / RemoveUser.
- internal/app: Factory gains Browser, Prompter, HTTPTransport,
  Credentials; SaveConfig, CredentialStore, ResolveHost (flag > FJO_HOST >
  defaults.host > the only host), AccountFor (FJO_TOKEN > active user's
  stored token), StoredAccount, APIClient, ClientFor. User-Agent
  "fjo/<version> (<platform>)". All tokens are registered with the redactor.
- internal/prompt (Input, Password without echo, numbered Select) and
  internal/browser (FJO_BROWSER / BROWSER, no launch over SSH, wslview on
  WSL, only http(s) URLs, argument arrays).
- internal/fjoerr: Silent errors (exit code without a printed message).
- internal/cli/cmdutil.AddHostnameFlag: -h/--hostname + hidden --host;
  defines --help without shorthand (cobra 1.10 panics on the -h clash).
- `fjo auth`:
  - login: -h/--hostname, --with-token (stdin), -w/--web, -p/--git-protocol,
    --insecure-storage, --insecure-http. Refuses when FJO_TOKEN is set and
    http:// without --insecure-http; verifies the token via GET /user and
    shows the server version; stores the token; adds the user as active;
    the first host becomes defaults.host. Interactive: host prompt + hidden
    token prompt.
  - logout: -h/--hostname, -u/--user; picks or prompts; deletes the token
    from both stores; the next user becomes active; empty host is removed.
  - status: -h/--hostname, -t/--show-token, -a/--active; verifies every
    token; gh-like report on stdout; exit 1 (silent) if any check fails;
    FJO_TOKEN is shown for the resolved host.
  - switch: -h/--hostname, -u/--user; the only other user, or a prompt.
  - token: -h/--hostname, -u/--user; prints the token (documented sensitive).
